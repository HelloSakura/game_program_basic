## 智能指针

指针指针，可以自动管理内存，实际上只是raw pointer的包装


### unique_ptr

域内自动管理，离开作用域自动回收
不能copy，底层实际上是将拷贝构造函数、赋值函数设置为delete


### shared_ptr

具体实现会随着编译器变化，底层机制是引用计数


### weak_ptr

来自shared_ptr的拷贝和复制不会增加引用计数


## 处理多返回值

C++提供的处理方式：
1.参数里面加入引用，函数里面对引用赋值；
2.同类型的对象返回一个数组指针；
3.返回std::array<T,N>, std::vector<T>, array是在栈上构建的，理论上更快；
4.返回对象中包含不同类型，使用std::tuple

处理方式：
1.使用结构体，结构体可以扩展，变量名的存在也增加了可读性


## 模板template

模板比其它语言（泛型）要牛逼的多
模板有点像宏，黑科技多，但是泛型非常受制于类型系统
解释：模板允许定义一个根据用途进行编译的模板（让编译器基于某套规则生成代码），简单来讲创造一个blueprint
如果发生了实际调用才会生成对应实际参数的代码（这个地方check由编译器决定）
**编译时会根据实际调用生成对应的代码**
meta programming元编程，编译器在编译时实际在进行编程

### 关于使用
不要一棒子打死，实际上还是很好用的
在日志系统或某种其它的使用场景下，比较好用
模板搞得太复杂，不知道在干嘛

```C++
template<typename T>
void print(T value) {
    cout << value << endl;
}
print(1);
print<string>("hello");

//可以使用具体的类型，本质还是在编译期实际调用时的替换生成
template<typename T, int N>
class Array{
    T arr[N];
}
Array<5> a;
```

## 宏

使用预处理来**宏化**某些操作，避免一遍又一遍来重复输入
本质上是文本的查找和替换
**正确的编程思路：不炫技，不要写令人迷惑的代码，努力写出好代码**
```C++
//简单的日志系统
#if _DEBUG = 1
#define Log(x) cout << "debug:"<< x << endl
#elif defined(_RELEASE)
#define Log(x)
#endif

Log("hello");
```
