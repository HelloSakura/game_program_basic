# 关于性能

优化最重要的事情之一就是优化内存访问；

## 内存

### 栈和堆

栈分配像是CPU指令，移动栈帧，得到内存地址，拷贝数据到内存中，栈比较快；
堆分配需要申请，调用malloc查询程序开始的freelist列表，看是否有符合条件的空闲内存，没有就要进一步像操作系统申请，需要维护一大堆结构；
通常来讲栈不会有cache miss，但是堆会有
本质的区别还是在分配上
**尽可能使用栈分配，除非条件不允许或者太大了**

## 让字符串更快

程序中大多数时候存在着大量的字符串操作，string的一些实现上，经常需要创建分配内存
看数据就能找到优化方法
string_view：不分配内存，使用窗口，本质上一个指向现有内存的指针加上串大小size
```C++
//0 memory allocate
void* operator new (size_t size) {
    static count size = 0;
    std::cout<<"Allocate "<<size<<" bytes"<<std::endl;
    return malloc(size);
}

void printString(std::string_view str) {
    std::cout << str << std::endl;
}

const c_str = "hello world";
std::string_view first(c_str, 5);
std::string_view second(c_str + 6, 5);
```


## 小字符串优化

SSO:(Small String Optimization)
C++标准库做了一点优化，长度低于16字节的string，会在栈上分配内存，而不是在堆上分配内存
