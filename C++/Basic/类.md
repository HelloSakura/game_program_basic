# 类

面向对象编程只是在编程时采用的编写代码的风格
简单来说，类是将数据和函数组织在一起的方式，变成一个类型
**永远使用引用或指针传递对象**

### 结构体和类的区别

唯一区别，访问控制上，类默认是私有的，结构体默认是公有的
C++中struct存在的原因，是想要维持与C之间的兼容性，因为C中没有类
仅仅是一堆变量组合的时候，用strcut；包含大量功能时，用class
绝对不会对struct用继承，会增加一层复杂性，破坏了struct仅仅是数据的设计

### 类中的static

静态成员变量，class对应的所有实例共享一份内存；
每一个非静态方法都会获得一个当前类的实例作为参数，这是类的实际工作方式
静态成员方法则没有实例参数，只能访问静态成员变量

### 生命周期与作用域

生命周期指变量能活多久（被删除之前在内存中停留的时间）
作用域指能在哪里访问到这个变量
static修饰变量的生命周期是整个程序

## 构造函数
C++类里面所有成员的初始化必须自己手动操作
屏蔽construct的两种方法（禁止类实例化）
```C++
class Entity{
private:
    Entity(){}  //声明构造函数为私有，外部无法调用
public:
    Entity() = delete;  //删除这个函数表示不可用
}
```

## 析构函数

一个特殊的函数当一个对象被销毁时调用
对于栈分配的内存会自动回收，对于堆内存需要手动回收，否则有内存泄漏


## 继承

避免代码重复，不必一次又一次重复，可以把类之间的所有公共功能都集成到父类中
**多态：一个类型具有多个类型，核心是子类具有父类的一切，是父类的超集合**


## 虚函数

虚函数允许我们覆盖父类的方法
如果只是正常声明函数方法，到调用的时候只会调用属于这个类的方法
如果是虚函数，会根据对象的类型调用对应的方法（虚函数引入动态分配，使用VTable，虚表包含基类中所有虚函数的映射，以便在运行时映射到正确的覆写函数）
虚函数有运行损耗：额外的内存存储虚表，以及调用虚函数的额外时间开销（每次都需要遍历虚函数表以查看该映射哪个函数）
**如果要覆盖函数，必须要在基类中将基函数标记为虚函数**

### 纯虚函数（接口）
纯虚函数，在声明的时候必须加上=0，表示这个函数是抽象函数，不能被实例化，只能被继承，子类必须实现这个函数
完全由纯虚函数构成的类，称之为接口（结合最近的编码，接口可以扩展类的功能）

## 访问控制

访问控制，本质是控制类中成员变量和方法的访问权限
friend友元可以访问类中私有成员变量和方法
**重要的是风格，重要的是如何编写易于维护且易于理解的代码，帮助他人理解**
**无关性能，无关产生的代码，计算机并不理解这一切，这只是人们发明出来帮助他人和自己理解**


## 成员初始化列表

为什么要使用这个：可以关注construct本身干的事情（变量的初始化混在一起，代码看起来不简洁）；
另一个原因是，提高性能，使用赋值初始化的方式会重复构造两次对象

```C++
class Entity{
private:
    int m_x, m_y;
public:
    Entity(int x, int y) : m_x(x), m_y(y) 
    {
        //把初始化的代码摘出去，更容易关注到函数本身干了啥
        initxx();
    }
}

```

## 拷贝
浅拷贝：只会拷贝一层，即对象声明的变量，对于分配内存的对象，只拷贝指针，指针指向的内存不会被拷贝；
**需要实现一个拷贝构造函数**
```C++
class Entity{
private:
    char* m_name;
    int m_size;
public:
    Entity(const char* name){
        m_size = strlen(name);
        m_name = new char[m_size + 1];
        memcpy(m_name, name, m_size);
        m_name[m_size] = '\0';
    }

    ~Entity(){
        delete[] m_name;
    }

    Entity(const Entity& other):m_size(other.m_size){
        m_name = new char[m_size + 1];
        memcpy(m_name, other.m_name, m_size+1);
    }
}
```

## 箭头函数

进阶一点：可以重载

```C++
//封装可以整点骚操作
```
