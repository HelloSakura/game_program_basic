# 基础了解


## 编译流程

只有cpp文件会被编译，被一个个单独编译成obj文件，通过链接器链接到一起组成可执行文件exe

**编译和链接是分开的两个过程**

vs配置工程选项可以看到中间工程文件（优化、中间文件都可以玩一玩）
vs outputList非常重要

### 预处理

处理所有的预处理指令
>1.#inlucde：实际是把头文件内容拷贝到当前文件

### 编译
>1.每一个cpp文件是一个编译单元（translation unit）
>2.生成对应的obj文件
>3.VS对应报错以C开头，便是编译错误

### 链接
>1.编译器根据函数签名进行联系
>2.链接器找到每个符号和函数的位置，将他们链接到一起
>3.VS对应报错以L开头，便是链接错误

关于static关键字，实际上是告诉编译器，这个函数或者变量只在当前文件中可见，不会被其他文件调用，仅为当前翻译单元声明


## 关键字

### static

类外使用表示表示在link阶段是局部的，只对定义它的编译单元可见
类内使用表示定义部分的内存是这个类的所有实例共享的（理解是类似于类的private成员）

### enum

**enum必须是一个整数**
简单来讲只是一种命名数值的方法，当想用整数来表示某些状态时，非常有用
enum可以指定使用的数据类型

```C++
enum example:unsigned char{

}
```


### const

const没有做任何事情，只是告诉编译器这些地方是“只读的”，编译器根据标注去检测使用时的正确性
一种规则，保持代码的简洁性（这种规则是可以被打破的）
重点是看const修饰的是什么，修饰的那个值是只读的
**从右向左，依次结合，const就近结合**
>1. 指向const变量的指针（const int *p）：指针指向的值不能被改变，指针指向的地址可以改变
>2. const指针（int* const p） ：指针指向的值可以被改变，指针指向的地址不能改变
>3. this是一个const指针，被const修饰的成员函数，相当于const指针指向一个const对象，函数内部不能修改变量值，除非被mutable修饰
>4. const int&用作返回值实际上表示的事，const指针指向const对象，&引用本身就是一个const指针

## new
为什么要用C++：需要关注内存、性能表现及优化
>1. new是在堆上分配内存，使用new是有时间损耗的，需要找空闲内存分配
>2. new不只是分配内存，还会调用构造函数
>3. new后一定记得delete
>4. new可以指定分配内存的地址起点

```C++
int* buffer = new int(10);
Entity* e = new(buffer) Entity();
delete e;
delete buffer;
```

## explicit

用于构造函数，禁止隐式转换
（C++编译器在赋值的情况下，如果一个类型到一个类型的隐式转换是允许的，会一直自动进行下去）
