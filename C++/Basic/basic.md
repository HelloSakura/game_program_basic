# 基础了解


## 编译流程

只有cpp文件会被编译，被一个个单独编译成obj文件，通过链接器链接到一起组成可执行文件exe

**编译和链接是分开的两个过程**

vs配置工程选项可以看到中间工程文件（优化、中间文件都可以玩一玩）
vs outputList非常重要

### 预处理

处理所有的预处理指令
>1.#inlucde：实际是把头文件内容拷贝到当前文件

### 编译
>1.每一个cpp文件是一个编译单元（translation unit）
>2.生成对应的obj文件
>3.VS对应报错以C开头，便是编译错误

### 链接
>1.编译器根据函数签名进行联系
>2.链接器找到每个符号和函数的位置，将他们链接到一起
>3.VS对应报错以L开头，便是链接错误

关于static关键字，实际上是告诉编译器，这个函数或者变量只在当前文件中可见，不会被其他文件调用，仅为当前翻译单元声明


## 关键字

### static

类外使用表示表示在link阶段是局部的，只对定义它的编译单元可见
类内使用表示定义部分的内存是这个类的所有实例共享的（理解是类似于类的private成员）

### enum

**enum必须是一个整数**
简单来讲只是一种命名数值的方法，当想用整数来表示某些状态时，非常有用
enum可以指定使用的数据类型

```C++
enum example:unsigned char{

}
```
