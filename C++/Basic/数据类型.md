### 使用String

注意作为参数传递的过程，避免值传递造成的拷贝开销
```C++
void printString(const string& str) {
}

//注意字符串在内存中的存储，放在了只读的常量区
char *str = "hello world";
str[2] = 'a';   //error，无法修改常量区的内存

char str[] = "hello world";
str[2] = 'a';   //ok，实际上是把常量区的字符串拷贝到栈上


```

## Vector

优化：主要是自动扩容时，复制原内存到新内存，这个过程有性能损耗，尤其是不断有这种类型操作
如何避免拷贝操作
**避免拷贝过程中，在传递过程中产生的新的对象**
**避免vector重新扩容，扩容时会被所有对象重新拷贝一次**
```C++
struct Pos{
    int x, y;
    Pos(int x, int y):x(x), y(y){}
    Pos(const Pos& other):x(other.x), y(other.y)
    {
        cout<<"Copy"<<endl;
    }
}

vector<Pos> posList;
posList.reserve(3);                 //提前指定大小，避免vector自动扩容
postList.push_back(Pos(1, 2));      //传递过程中，会调用拷贝构造函数
postList.emplace_back(3, 4);        //使用提供的参数直接构造对象
```
