# 基础语法

## 变量

实际上没有那么多区别，不同变量类型之间唯一的区别是大小（占多少个byte）
不同大小表示的数据大小范围不一样，整数、叠加式符号位、浮点数的表示规则，实际上就是在进一步表示不同范围的数据


## 函数

简单来讲，封装一段代码，接受输入，返回对应输出


## 指针

编程中最重要的东西：内存
**指针是一个整数，存储一个内存地址**，（指针类型没有意义，只是标识指针那个地址上可能的数据类型，只在读入写入的时候告诉编译器怎么操作
不改变指针的本质，就是一个存储内存地址的整数）

运算符‘*’：解引用指针，获取指针指向的内存地址的值，读取或写入那块数据


## 引用

引用：对某个已存在变量的引用，本身并不是一个新变量，是变量的一个别名，并不真正占内存（不存在赋值的情况，因为没有地方存储数据，**只是对其它变量的引用**）
引用只是指针的一个拓展，计算机的角度来看，指针和引用是一回事
只是使用的时候有些不同，引用是指针的一个语法糖
一旦引用被初始化，其引用的对象不能再次通过赋值改变引用的对象（实际上是一个变量的别名，赋值的过程中就被绑定到一起，编译上来讲是同一个变量，内存地址是一致的）


## 类

面向对象编程只是在编程时采用的编写代码的风格
简单来说，类是将数据和函数组织在一起的方式，变成一个类型

### 结构体和类的区别

唯一区别，访问控制上，类默认是私有的，结构体默认是公有的
C++中struct存在的原因，是想要维持与C之间的兼容性，因为C中没有类
仅仅是一堆变量组合的时候，用strcut；包含大量功能时，用class
绝对不会对struct用继承，会增加一层复杂性，破坏了struct仅仅是数据的设计
