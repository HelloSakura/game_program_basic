# 工程相关


## 库文件
### 静态库
静态链接是编译时进行链接
链接二进制文件，库通常文件结构包含两部分，includes和library，包含目录和库目录
对于VS，包含头文件，将链接器指向库文件（先将将头文件和库文件拷贝到对应目录）
1.指定链接库的文件路径；
2.相对于库目录的库文件名称；


### 动态库
动态链接是运行时进行链接
确保有一个可访问的dll文件，同样需要配置编译器的动态库路径
关于动态库的位置：
1.直接放在exe目录下；
2.放在系统目录下；

### 创建和使用库

反复利用代码，混合其它语言
VS需要设置工程属性，一种特定的结构
记一下这种工程项目结构
Engine
|--Engine.h
|--Engine.cpp
Game
|--Game.h
|--Game.cpp
通过静态链接将两个连到一起，分离的好处，几个游戏可能共用同一个引擎文件，这种模块化的处理方式，将所有核心代码集中到一个项目中
