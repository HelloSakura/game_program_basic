# 虚指针和虚表

每个使用虚函数的类（or 从使用虚函数的类派生）都有自己虚拟表；
虚表：编译器在编译时设置的静态数组，包含可用类得对象调用的每个虚函数的一个条目，表中的每个条目只是一个函数指针，指向改类可访问的派生函数；

编译器还会添加一个隐藏指向基类的指针，我们称之为vptr。vptr在创建类实例时自动设置，以便指向该类的虚拟表

Base:
    VPtr{
        func1*;
        func2*;
    }

    virtual func1();
    virtual func2();

Derived:
    VPtr{
        func1*;
    }
    virtual func1();

## 多态实现
  如果一个父类的指针或者引用调用父类的虚函数则该父类的指针会在自己的虚函数表中查找自己的函数地址，如果该父类对象的指针或者引用指向的是子类的对象，
而且该子类已经重写了父类的虚函数，则该指针会调用子类的已经重写的虚函数

```C
// C实现多态
// 继承实现 结构体中定义一个父类对象
typedef void (*pFunc)();

typedef struct Base{
    pFunc _f;
}Base;

typedef struct Derived{
    Base _base;
}Derived;

void funcA(){ printf("Base:funcA\n");}
void funcB(){ printf("Derived:funcA\n");}

// 多态实现
Base base;
Derived derived;

base._f = funcA;
derived._base._f = funcB;

Base* pa = &base;
pa->_f();
pa = (Base *)&derived;
pa->_f();
return;

```
