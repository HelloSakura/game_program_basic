## 环境和全局环境

Lua的环境（Environment） 决定了变量和函数的可见性，而 全局环境（Global Environment） 是所有 Lua 代码默认共享的命名空间。理解它们的关系对模块化编程和沙盒安全至关重要

### 全局环境 _G

_G 是 Lua 的全局表，存储所有全局变量和函数;
默认情况下，所有全局变量都存储在_G 中'

### 环境

每个 Lua 函数或代码块可以有自己的 环境（一个表），用于解析自由变量（未显式声明的变量）

```lua
-- lua 5.2+
local env = {x = 100}
_ENV = env
print(x)
```

### 模块与环境

模块隔离全局变量：模块通常通过 local 变量和返回表避免污染 _G：
自定义环境限制访问权限：

```lua
local sandbox_env = {
    print = print,
    math = math,
    -- 只允许访问白名单函数
}
function run_safe(code)
    local fn, err = load(code, "sandbox", "t", sandbox_env)
    if fn then
        return fn()
    else
        print("Error:", err)
    end
end
run_safe("print(math.sqrt(4))")  -- 输出 2
run_safe("os.execute('rm -rf /')")  -- 报错：未定义 os
```

## 错误处理

raise错误，会打断程序的正常流程，可以通过catching错误来继续
可显示调用error显示抛出
可以使用pcall或者xpcall来发起一个保护调用，pcall函数将在 保护模式（protected mode） 下调用给定函数。任何错误的产生都会停止执行函数，**控制流直接返回到pcall调用处**，并返回其状态码


## 元表和元函数

Lua 中的每个值都可以有一个元表，定义了原始值在特定事件下的行为，可以通过设置其元表中的特定字段来更改值的多个行为方面
表和完整用户数据有单独的元表，尽管多个表和用户数据可以共享它们的元表。所有其他类型的元表都共享一个单一的元表
Lua 使用的所有元表键都由两个下划线和拉丁小写字母组成

```lua
local t = {a = 1}
local mt = {
    __index = function(table, key)  -- 当table不是表或当key不存在于table中时，会发生此事件
        print("尝试访问不存在的键: " .. key)
        return 0 -- 默认返回值
    end
    -- 或者可以直接指向另一个表:
    -- __index = {b = 2}
}
setmetatable(t, mt)

print(t.a) -- 输出: 1 (存在)
print(t.b) -- 输出: "尝试访问不存在的键: b" 然后输出 0
```


## 垃圾回收

Lua使用的所有内存都受自动管理：字符串、表、用户数据、函数、线程、内部结构等
只要收集器能够确定在程序的正常执行过程中不会再次访问对象，该对象就会被视为死亡；
注意收集器确定的死亡时间与**程序员可能预期不一致的问题**

Lua 中的垃圾收集器 (GC) 可以使用两种模式：增量模式和代际模式


## 弱表

弱表是 Lua 中一种特殊的表，它不会阻止其键(key)或值(value)被垃圾回收器回收。弱表是实现缓存、观察者模式等场景的重要工具。


## 协程

Lua 支持协程，也称为协作式多线程。Lua 中的协程表示一个独立的执行线程。然而，与多线程系统中的线程不同，协程仅通过显式调用 yield 函数来挂起其执行。
通过调用 coroutine.create 创建协程
通过调用 coroutine.resume 执行协程
协程可以通过两种方式终止其执行：正常终止，即当其主函数返回时（显式或隐式，在最后一条指令之后）；以及异常终止，即如果存在未受保护的错误；

协程通过调用 coroutine.yield 来 yield。当协程 yield 时，相应的 coroutine.resume 立即返回，即使 yield 发生在嵌套函数调用中（即，不在主函数中，而是在主函数直接或间接调用的函数中）。在 yield 的情况下，coroutine.resume 还返回 true，以及传递给 coroutine.yield 的任何值。**下次恢复同一协程时，它将从 yield 的位置继续执行**，coroutine.yield 调用返回传递给 coroutine.resume 的任何额外参数
