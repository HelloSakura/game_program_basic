## 环境和全局环境

Lua的环境（Environment） 决定了变量和函数的可见性，而 全局环境（Global Environment） 是所有 Lua 代码默认共享的命名空间。理解它们的关系对模块化编程和沙盒安全至关重要

### 全局环境 _G

_G 是 Lua 的全局表，存储所有全局变量和函数;
默认情况下，所有全局变量都存储在_G 中'

### 环境

每个 Lua 函数或代码块可以有自己的 环境（一个表），用于解析自由变量（未显式声明的变量）

```lua
-- lua 5.2+
local env = {x = 100}
_ENV = env
print(x)
```

### 模块与环境

模块隔离全局变量：模块通常通过 local 变量和返回表避免污染 _G：
自定义环境限制访问权限：

```lua
local sandbox_env = {
    print = print,
    math = math,
    -- 只允许访问白名单函数
}
function run_safe(code)
    local fn, err = load(code, "sandbox", "t", sandbox_env)
    if fn then
        return fn()
    else
        print("Error:", err)
    end
end
run_safe("print(math.sqrt(4))")  -- 输出 2
run_safe("os.execute('rm -rf /')")  -- 报错：未定义 os
```

## 错误处理

raise错误，会打断程序的正常流程，可以通过catching错误来继续
可显示调用error显示抛出
可以使用pcall或者xpcall来发起一个保护调用，pcall函数将在 保护模式（protected mode） 下调用给定函数。任何错误的产生都会停止执行函数，**控制流直接返回到pcall调用处**，并返回其状态码
